# Game adjustments — 2026-10-16

## Nearest-target preference with a switching delay — 2026-10-17

Auto aim now reconsiders the nearest visible target while the current lock remains valid. Enemy priority over fallback crates is retained. Among equal-priority targets, distance is measured from a stable pilot-relative position rather than the animated forearm. Each acquisition/change holds its choice for 0.65 seconds before another valid target can replace it. A challenger must be at least 0.15 units closer, preventing near-tie distance noise from swapping targets repeatedly. Both values are authored in Settings/Guns/SecondarySMG. Invalid/dead/off-screen targets still release normally and use the existing reacquisition delay; the previous smooth locked tracking and native capture feedback remain.

## Current projectile platform rules — 2026-10-17

The latest request prioritizes readable, forgiving projectile travel. Bullets pass through the platform layer using native SphereCollider exclusion settings, while their Rigidbody/CCD still resolves enemy, crate and ground contacts. The collision mask is authored in SecondaryWeaponSettings and applied to each bullet instance; actor/platform collision rules do not require a global matrix change.

Spears capture the player aim point (including bounded horizontal lead) and intended support at release. A native downward query finds a landing surface for an airborne player. The server plans a ballistic tip path through the captured aim toward that surface, with a small follow-through clamped inside its edges. Throws can begin upward, downward or nearly straight, and can land on the same platform as the thrower. Intervening decks and the destination underside during ascent are traversable: there is no fixed platform-count allowance or requirement to land one level lower. The player remains hittable throughout flight. A dodge does not retarget the spear; it continues to the captured landing, embeds in scenery and cleans up after 1.5 seconds. EnemyLanceSettings owns speed, minimum flight time, landing follow-through, edge inset and landing-query layers/depth. Shared settings are never mutated during play.

Their model geometry sits 1.2 units toward the camera, ahead of platform art, while collision/trajectory stay on the combat plane. The native sphere and imported spear mesh/materials remain in use; no custom rendering shader or procedural projectile shape was introduced. The repeatable projectile authoring methods apply the collision mask, model depth and sorting layer through Unity APIs.
